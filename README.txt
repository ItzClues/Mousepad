APK kaise banayen (free, GitHub par)
1. github.com par account banayen, naya repository banayen (New repository).
2. "uploading an existing file" se is zip ka SARA content upload karen (folder .github samet), Commit karen.
3. Repository ke "Actions" tab mein "Build APK" chalne den (3-5 min). Na chale to Run workflow dabayen.
4. Complete hone par us run mein neeche Artifacts se "TabRemote-apk" download karen, zip kholen, app-debug.apk Tecno mein copy karen.
5. Tecno mein install karen ("Unknown sources" allow karna hoga).

Istemal
1. Tecno par Tab Remote kholen, button se Accessibility settings jayen, Tab Remote ON karen.
2. App par jo address likha hai (http://192.168.x.x:8080) Tab A6 ke browser mein kholen. Dono ek hi WiFi par hon.
3. Touchpad: 1 ungli cursor, tap click, 2 ungli scroll, 2 ungli tap = Back. Keyboard button se typing.
